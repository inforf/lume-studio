# Lumé Studio

Landing page responsiva criada como **projeto demonstrativo de portfólio** para o segmento de beleza.

## Objetivo

Demonstrar desenvolvimento front-end de uma página comercial moderna, responsiva e orientada a conversão.

## Recursos

- HTML5 semântico
- CSS responsivo para desktop, tablet e celular
- JavaScript para navegação mobile
- Microsoft Clarity para análise de navegação e interação
- Banner de privacidade com escolha para cookies de análise
- Preferência de consentimento armazenada localmente no navegador
- Seções de serviços, sobre, galeria, depoimentos e contato
- Design original em tons quentes e rosé
- SEO básico, Open Graph e cuidados de acessibilidade estrutural

## Privacidade

O projeto informa o uso do Microsoft Clarity e oferece ao visitante a opção de aceitar ou recusar cookies de análise. O script do Clarity só é carregado após a aceitação registrada no navegador.

A implementação foi pensada para demonstrar boas práticas de transparência e controle do usuário. Em um projeto comercial real, a política de privacidade, a base legal aplicável, os responsáveis pelo tratamento e demais requisitos devem ser definidos de acordo com o contexto da empresa e a legislação aplicável.
